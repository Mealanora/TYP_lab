# ТЯП — Лабораторная работа №1

Транслятор арифметических выражений с присваиванием в ассемблероподобный код. Программа разбирает выражение с помощью конечного автомата, переводит его в обратную польскую запись (ОПЗ), строит дерево разбора, генерирует код и оптимизирует его.

## Пример

**Вход (`input.txt`):**

```
A = 2 * (1 + B)
```

**Выход (`output.txt`):**

```
Таблица имён:
 1       A		Переменная с плавающей точкой
 2       2		Константа с плавающей точкой
 3       1		Константа с плавающей точкой
 4       B		Переменная с плавающей точкой

Неоптимизированный код:
LOAD	B
STORE	$1
LOAD	=1
ADD		$1
STORE	$1
LOAD	=2
MPY		$1
STORE	A

Оптимизированный код:
LOAD	B
STORE	$1
LOAD	=1
ADD	$1
STORE	$1
LOAD	=2
MPY	$1
STORE	A
```

## Возможности

- Операторы: `=` (присваивание), `+`, `*` с приоритетами `=` < `+` < `*`.
- Скобки любой вложенности с проверкой баланса.
- Переменные: буквы латиницы, цифры и `_`.
- Вещественные константы: десятичная точка, экспонента `e` / `E`, знак порядка (например, `1.5e-3`).
- Таблица имён с разделением на переменные и константы.
- Диагностика синтаксических ошибок.

## Как это работает

1. **Конечный автомат** (`ExpressionStateMachine`, `TransitionMatrix`) посимвольно читает выражение. Для каждой пары «состояние — символ» задан переход и действие (сборка токена, работа со стеками скобок и операторов). Результат — ОПЗ (алгоритм сортировочной станции).
2. **Таблица имён** (`Generator.generateTable`) — список всех переменных и констант из ОПЗ.
3. **Дерево разбора** (`Generator.generateTree`) строится из ОПЗ; каждому узлу назначается уровень, который используется для номеров временных переменных `$N`.
4. **Генерация кода** (`Generator.generateUnoptimizedCode`) — обход дерева с выдачей команд `LOAD`, `STORE`, `ADD`, `MPY`.
5. **Оптимизация** (`Generator.generateOptimizedCode`):
   - перестановка `LOAD` с последующими `ADD` / `MPY` (коммутативность операций);
   - удаление пар `STORE x` → `LOAD x`;
   - упрощение цепочек `LOAD` – `STORE` – `LOAD` с подстановкой временных переменных.

## Система команд

| Команда | Действие |
|---------|----------|
| `LOAD x`  | загрузить `x` в сумматор (`=c` — константа) |
| `STORE x` | сохранить сумматор в `x` |
| `ADD x`   | прибавить `x` к сумматору |
| `MPY x`   | умножить сумматор на `x` |

`$N` — временные ячейки для промежуточных результатов.

## Структура проекта

```
src/
├── input.txt                       # входное выражение
├── output.txt                      # результат работы
└── lab1/
    ├── Main.java                   # точка входа
    ├── Generator.java              # таблица имён, дерево, генерация и оптимизация кода
    ├── state_machine/
    │   ├── ExpressionStateMachine.java  # автомат, перевод в ОПЗ
    │   ├── TransitionMatrix.java        # матрица переходов и классификация символов
    │   └── State.java                   # состояния автомата
    ├── tree/
    │   └── TokenTree.java          # узел дерева разбора
    └── util/
        ├── Action.java             # интерфейс действия автомата
        ├── DeltaCell.java          # ячейка матрицы (состояние + действие)
        ├── FileHelper.java         # чтение входного / запись выходного файла
        └── Symbols.java            # наборы символов
```

## Запуск

Требуется JDK 8 или новее.

1. В `FileHelper.java` укажите свои пути к `input.txt` и `output.txt` (сейчас там абсолютные пути с локальной машины):

   ```java
   private static final String inputFile  = "путь/к/src/input.txt";
   private static final String outputFile = "путь/к/src/output.txt";
   ```

2. Запишите выражение в `input.txt`.
3. Соберите и запустите:

   ```bash
   javac -encoding UTF-8 -d out src/lab1/*.java src/lab1/*/*.java
   java -cp out lab1.Main
   ```

   Либо запустите `Main` из IntelliJ IDEA.

4. Результат появится в `output.txt`. При ошибке в выражении будет выведено сообщение «Ошибка при анализе выражения».

## Ограничения

- Поддерживаются только операции `+`, `*` и присваивание `=`.
- Выражение должно содержать одно присваивание вида `переменная = выражение`.
